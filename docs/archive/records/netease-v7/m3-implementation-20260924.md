## 范围与设计

喜欢集合 / 明确喜欢目标、ID 打开歌单、收藏 / 取消、普通歌单创建、名称和描述分别保存、目标选择与添加、移除及删除确认均已接入。共享协调器处理一次写入与有限只读回查；页面草稿 Scoped，账号与表单代次拒绝迟到结果。普通 MVVM 和三个业务端口保持 SOLID 分工，不添加通用工作流或重放队列。

WebView2 Core 只用于按需获取网易官方令牌；失败为零写入，运行时、隐私及实际验证范围见当前契约。库修改不改变播放队列。新增测试覆盖原始请求、Unicode、权限、部分结果、存储失败、预算、双页面、20 次挂卸、各歌曲来源、鼠标 / 键盘 / 焦点、12 组布局和截图。
