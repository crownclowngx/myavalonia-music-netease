# V3 紧凑界面与主题专用开发验证

> 状态：实施中；创建日期：2026-09-23。范围仅 MusicNetEasePlugin Document / Tool。
> 设计依据：[V3 方案](../roadmap/netease-v3-desktop-ui-and-theme-plan.md)。不使用 AIFLOW、Windows CI 或发布门禁。

## 验证边界

保留 M1 全量自动回归及真实离线 LibVLC 解码，增加 V3 的主题、宽窄布局、偏好保存、动画寿命与视图重挂检查。专用测试使用真实生产 View、可控业务数据和明确的布局断言；真实 Host、系统主题联动、显示缩放及扬声器听感单独留证。

| 范围 | 必须验证的结果 |
| --- | --- |
| 主题 | Light/Dark 资源解析与同实例切换；二维码白底例外；插件不改 Application 资源 |
| Document | 1200×720、800×600、520×420 下操作可达，结果填充剩余空间，播放条固定 |
| Tool | 280/320/420 宽与 640×240 下草稿、已保存、候选及实际值分开；长路径可编辑 |
| UI 偏好 | 默认、恢复、保存失败、快速更改与迟到读取；多个 View 同步；和账号/运行库文件隔离 |
| 动效 | 有效可见性、最小化、重挂、减少动态效果与主题变化及时收口；不逐帧重建对象 |
| 生命周期 | 20 轮重挂；无双播、无草稿丢失；目录选择迟到结果继续受保护 |
| 门禁 | 必测方法与 TRX 通过结果对应；截图和资源数据属于本次目录；缺项或失败必须拒绝 |
