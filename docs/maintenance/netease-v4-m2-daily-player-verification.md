## 2. 自动业务场景

表中是**场景数，不是预计测试数**。每个参数组合必须落到实际测试方法及执行用例数；断言覆盖可观察行为，不仅断言 mock 被调用。所有场景当前均为待实施/待执行。

### P：歌单与曲目（8 项）

| ID | 场景 | 必须断言 |
| --- | --- | --- |
| P01 | 用户歌单、详情、批量详情、两种歌词请求编码 | 固定端点/协议/参数、long ID；请求级会话、取消和 Cookie 提交沿用既有契约；夹具期望独立于被测编码器 |
| P02 | 自建/收藏、多页重复项、空页、最后一页、重复页 | 按服务端原始数量推进 offset；去重不漏后续项；无进展停止；分类来源真实 |
| P03 | 打开 A→B、刷新与旧分页并发、退出期间返回 | 旧结果不覆盖新页面；失败/取消不残留 Loading；刷新不修改共享队列 |
| P04 | trackIds 含重复 ID，详情乱序/缺失/多返回 | 原位置、顺序和条目身份不变；缺失可解释，未知额外详情不混入 |
| P05 | 完整 ID 快照、只加载第一批、播放全部或从中间播放 | 队列包含所有已确认 ID，当前起点正确；未完整/超限快照不提供假“全部” |
| P06 | 10,000 条 ID、50 条批次、2 批并发和缓存淘汰 | 请求并发、资料缓存和实例化行有上限；可见区外不全量补详情；不以万条完整 DTO 堆满界面 |
| P07 | HTTP/正文错误、私密不可访问、缺字段、限额/解压超限 | 错误分类与重试入口准确；单个内容问题不退出账号；不返回截断成功 |
| P08 | 一页失败后重试、快速换页、列表在远端变化 | 本地不会重复追加同页或乱序；重新刷新建立新快照，显示加载/空/失败与限制状态 |

### Q：队列与模式（12 项）

| ID | 场景 | 必须断言 |
| --- | --- | --- |
| Q01 | 替换全部、从此处播放、搜索/历史直接播放 | 替换原子完成；明确起点；旧优先段与导航历史失效；选择行不等于播放项 |
| Q02 | 重复歌曲、下一首播放连续两次、追加 | 独立 EntryId；优先段 FIFO 且先于模式；追加不打断播放，空队列追加不出声 |
| Q03 | 移除非当前项、调整顺序 | 当前 EntryId/位置/音源不变；优先段与随机候选同步修剪 |
| Q04 | 移除当前项：播放/暂停/停止/加载、首/中/尾/仅一项 | 按方案选择剩余项并保留明确的播放意图；旧曲先释放，不发生意外播放 |
| Q05 | 清空与停止，各状态重复调用 | 清空完全归零且持久化不复活；停止保留队列、位置归零；命令幂等 |
| Q06 | 顺序：首项上一首、末项下一首、自然结束；播放/暂停/加载中手动切换 | 边界禁用；末曲 Ended 保留结尾，不能回首或自动重播；手动切换按原意图继续或停留待播 |
| Q07 | 列表循环：首尾、空队列、单项 | 自然结束正确回绕；空/单项手动按钮符合约定 |
| Q08 | 单曲循环：自然结束与手动下一首 | 自然重复当前项，手动移动；有优先项先消费，失败不无限重复 |
| Q09 | 随机：可控随机源、一轮、下一轮、前后历史 | EntryId 无放回；多项时换轮不紧接当前项；上一首回实际历史，下一首先走前进历史 |
| Q10 | 随机中插入优先项/追加/移除/切换模式 | 已消费优先项不在同轮再次抽中；删除历史安全；模式切换不重启音频 |
| Q11 | 开头不可播、中间缺失、全部不可播、超过 20 项 | 每个候选一轮最多一次；20 次/候选耗尽有硬停止；摘要准确、没有递归忙循环 |
| Q12 | 网络/限流/存储/设备/协议/账号错误 | 全局性错误停止扫描；保留可重试上下文；不逐曲放大请求或误判歌曲权限 |

### C：竞态、终态和释放（6 项）

| ID | 场景 | 必须断言 |
| --- | --- | --- |
| C01 | A→B→C，在详情/地址/缓冲/打开处分别阻塞再释放 | 只有 C 接管；A/B 迟到结果和原生事件不能改快照；最多一个有效音源 |
| C02 | Ended 重复、Failed 后 Ended、主动 Stop 后迟到 Ended | 终态消费至多一次；主动停止/取消不续播；有带代次的结束原因 |
| C03 | 手动下一首与 Ended 同时；同时追加/删除当前项 | 无双跳、跳错身份或漏掉下一项；最后接纳意图胜出，追加不废掉当前曲事件 |
| C04 | 旧曲 seek/暂停等待原生门时换曲；用户拖动多次 | 门内二次核验代次；旧控制不落到新曲；拖动仅最后目标可生效 |
| C05 | 请求/保存/原生事件进行时退出或重复 Shutdown | 立即阻止新意图；等待同一收口任务，无死锁；终止前保存位置不被 Stop 归零覆盖 |
| C06 | Stop/解绑/删文件失败、重复销毁与容器回收 | 先停输出再释放媒体文件；保留可恢复错误，不强删占用文件；无订阅/计时器/句柄持续增长 |

### B：定位、缓冲和受控恢复（8 项）

| ID | 场景 | 必须断言 |
| --- | --- | --- |
| B01 | 已知/未知 Content-Length、持续进度、超大/截断/取消 | 已读字节准确、不虚构百分比；文件未完成不能 seek，失败清理 partial |
| B02 | 本地 MP3/WAV 前跳/后跳，正常播放中定位 | 实际适配 Position 进入预定容差且解码内容变化；不能仅验证 setter 被调用 |
| B03 | 暂停中 seek、seek 失败或超时 | 暂停状态保留，无自动继续；失败显示实际位置与提示，草稿不变成事实 |
| B04 | 负位置、超结尾、未知时长、不可定位、试听 | Clamp/禁用准确；试听可播边界与歌词 offset 按核验事实处理 |
| B05 | 拖动遇进度事件/换曲/退出、鼠标与键盘 | 草稿不被回推；松手合并提交；曲目变化丢弃草稿，CanExecute 同步 |
| B06 | 明确地址过期与网络失败组合，普通 403、取消 | 媒体尝试总预算 ≤3、地址重取 ≤1；重试等待可取消；拒绝/取消不重放 |
| B07 | 下载中断、完整缓存后断网、下一曲网络失败 | 不播放未完成文件；已缓存当前曲继续；下一曲有限恢复后停止，不无限换歌 |
| B08 | 保存位置恢复后首次点击继续；近结尾、权限/时长改变 | 恢复初始化不建媒体、不输出；重新解析地址后从有效位置开始，无开头短暂音频；超时/失败可重试 |

B02/B03/B08 必须使用真实适配和已知内容的本地样本，记录版本、样本哈希、目标/实际位置、容差依据、PCM 区段与停止后资源状态。离线可用有区别的分段音频检查错误地从开头输出；不能把“接收到 PCM”当作正确定位。真实网易 MP3 和声卡听感由 R02/R03 补验。

| Y02 | 无歌词、纯音乐、纯文本、坏行、过量输入 | 可解释空态/文本态；上限有效，坏轨道不能让播放失败 |
| Y03 | 播放/暂停/前后 seek/首句前/末句后 | 用真实媒体位置选择行，seek 后立即重算，暂停不自行推进 |
| Y04 | 翻译缺行/不同时间，逐字时长/重叠/损坏 | 不按下标错配；合法逐字高亮边界正确，缺失降级逐行 |

| Y07 | 缓存满、请求失败重试、超大歌词、试听时间映射 | 缓存有界且退出清空；错误独立于播放；未知试听 offset 明确降级 |

### H：本地历史与恢复（8 项）

| ID | 场景 | 必须断言 |
| --- | --- | --- |
| H01 | 点选、失败、Playing 无进度、正常推进、seek、重播 | 只在真实正常推进后记历史；每 generation 一次，TrackId 去重，上限 200 |
| H02 | 保存与重读、同歌重复入队、不同账号 | EntryId/顺序/当前项/模式/音量/位置可恢复；文件账号与请求账号一致 |

| H04 | JSON 损坏、未知版本、超大文件、坏 ID/当前项/数值 | 安全拒绝并提示，不越界加载/静默覆盖原文件；用户新建状态的覆盖动作明确 |
| H05 | 保存中断、磁盘满/无权限、原子替换失败 | 上次完整文件仍可读取；当下播放继续，保存失败状态可重试 |

| H08 | 退出时迟到保存/清空后旧保存、会话失效再登录 | 显式退出续播状态不复活；历史按账号保留但内存清空；清理失败可见，会话失效按方案保留恢复记录 |

## 3. 门禁实现及失败注入（G01–G06）

V4 自动入口要执行：脚本自测 → locked restore → Debug 零警告构建 → 全量测试 → TRX 完整性 → M1/V3/M2 场景映射 → 本轮证据校验 → 文档链接/锚点 → `git diff --check`。使用现有工具扩展，不复制第二套发布检查。

M2 映射拟为 `tools/m2-test-map.json`：`schemaVersion`、`methods`（真实全限定方法名→最小参数化用例数）、`scenarios`（场景→方法）。必测集合由校验器独立维护：P01–P08、Q01–Q12、C01–C06、B01–B08、Y01–Y07、H01–H08、A01–A04、U01–U05，共 58 个自动场景。编号不能仅出现在 Trait/文档里；TRX 必须存在对应通过结果，且场景与方法的语义映射经审阅。

| ID | 注入与检查 | 预期 |
| --- | --- | --- |
| G01 | 命令非零退出、超时、零测试、失败/跳过/中断、统计不一致、非法 XML/DTD | 全部拒绝；失败退出不能生成“通过”摘要 |
| G02 | 删除任一必测场景、空映射、方法改名、参数化用例减少、未执行方法 | 全部拒绝；不能靠更改映射掩盖未完成需求 |
| G03 | 旧 TRX/其他运行目录结果/缺运行时间/新摘要配旧证据 | 拒绝；runId、时间、源码 revision 与工作树 dirty 绑定到本轮 |
| G04 | 缺解码/定位数据、无效截图、伪造 Headless 为真实 Host、错误恢复输出结果 | 拒绝；检查定位容差、有效 PCM 区段、来源及字段内容，不只检查文件存在 |
| G05 | V4 漏跑 M1/V3 映射/产物，或变更关闭语义只删除旧覆盖 | 拒绝/审查不通过；保留回归集合并明确迁移到 A03/A04/C05，更新实际方法映射 |
| G06 | 断开的文档链接、无效锚点、Git 空白问题、虚构已实施入口 | 文档检查失败或审查不通过；方案、当前契约、证据三者一致 |

G05 的旧语义迁移、G06 的事实一致性包含人工审阅，脚本不能自动理解业务语义。不得宣称脚本检查已替代审阅。

每轮使用 `TestResults/NetEaseV4/<runId>/`，自动摘要保留 `revision`、`workingTreeDirty`、开始结束时间、运行库版本/来源、TRX、M1/V3/M2 映射统计与实际产物清单。真实账号、实际声卡输出、Host、部署、发布字段默认为 false；只能由相应单独记录支持，发布字段本阶段始终 false。

新增产物约定：`m2-native-seek.json`（真实适配定位/静默恢复）、`m2-lifetime.json`（队列切换/挂载/资源收口观测）、`m2-document-<theme>-<width>.png`（两主题×三尺寸，1200 展示歌单、800 展示队列、520 展示歌词）、`m2-restored-paused-<theme>.png`（静默恢复状态）。字段结构随 V4.0 夹具冻结并补失败注入；保留既有 M1/V3 要求的产物。截图须结合布局断言及人工视觉审阅。

阶段开发可以运行相关测试与既有 V3 基线，但必须报告“V4 部分阶段验证”。只有 58 个自动场景、既有回归和证据检查齐全后，才报告完整 V4 自动门禁通过；不要给完整入口设置跳过未实现阶段的开关。

## 4. 必须单独留证的真实验收（R01–R06）
