# V8 · M4 音乐发现专用验证矩阵

> 编写日期：2026-09-25。状态：**V8 测试、方法映射、门禁和自动产物已实现；实际运行结果见专用实施记录，M01～M06 真实验收待执行**。
> 对应[V8 实施计划](../archive/plans/netease-v8-m4-music-discovery-plan.md)。覆盖推荐 / 榜单、歌手 / 专辑、私人 FM、远端记录及与现有播放器的协作。
> 只使用本地开发门禁，不使用 AIFLOW、Windows CI 或发布门禁。默认本地开发入口为 V8，保留 V7 及全部适用前置回归。

## 1. 分层、计数与通用断言

| 层次 | 对象 | 方法与证明边界 |
| --- | --- | --- |
| 单元测试 | 来源 / 分页、身份、队列意图、FM 状态 / 预算 / 去重、反馈结果、账号和取消 | 复用 xUnit、Fake、`FakeTimeProvider`、受控任务完成顺序；无真实业务网络 |
| 协议 / HTTP 测试 | 固定模块对应的请求、参数编码、必需字段、业务错误及 Cookie 提交 | 复用 Flurl 拦截 / 协议夹具；每端点有成功、拒绝、损坏响应；反馈增加不确定发送场景 |
| 集成 / UI 自动测试 | 生产 View、按钮、菜单、导航、抽屉、布局、真实队列协调器和生命周期 | 使用生产控件 + Fake 业务边界，Avalonia Headless / Skia；不以替代页面冒充生产交互 |
| 门禁自测 | 错映射、漏前置、坏证据、失败 / 跳过等必须阻断 | PowerShell 临时合成正反例；不能作为业务功能已通过的证据 |
| 人工验收 | 真实网易账号返回、FM 反馈、真实 Host、声卡和物理输入 | 带日期记录；真实写入单独明确目标与意图，不进入默认门禁 |

本矩阵有 **50 个自动业务场景**：A6 + D6 + W6 + P4 + F10 + H4 + C6 + U5 + R3。G01～G06 是门禁自测，M01～M06 是人工验收，均单独记录，不计入业务 TRX 场景数。参数化用例数量在实现后以真实方法 / 数据行登记，50 不代表测试方法总数。

所有自动测试使用合成账号 / 凭据、隔离临时目录和受控数据，不读取用户保存会话、私有推荐 / 历史，不连接网易业务，不向系统音频设备出声。优先验证可观察行为：请求次数与参数、被接纳的 QueueRevision / EntryId / AttemptId、事件次数、媒体打开数、快照和状态，而非仅断言一个 `IsBusy` 或枚举值。

预算测试覆盖上限前、等于上限、超过上限、等待点取消和请求剩余时间；通过可控时钟推进，不依赖数十秒真实睡眠。并发测试明确安排 A 请求迟于 B 返回、UI 已排队后换账号等顺序，不依赖随机线程调度碰巧命中。

每个候选端点都必须关联实际测试方法，不允许仅用一个推荐接口的测试代表所有端点。参考模块未提供真实响应依据时，合成夹具只证明约定的本地行为，记录中单列线上待核验项。

| --- | --- | --- |

| V8-F04 | 不可播放候选跨多个批次、网络 / 协议 / 设备错误、429、验证要求 | 连续自动失败链最多 20 个不同候选；不随补取清零；非内容错误立即停止；限流不自动绕过 |
| V8-F05 | 暂停、暂停时 Next、继续、Stop / Clear、结束 FM、外部普通点播 / 追加 / 改模式、尝试上一首 | 暂停无新自动预取 / 出声；FM 上一首禁用且应用层拒绝；普通意图先退出 FM；模式及普通导航恢复，无隐藏队列回滚 |
| V8-F06 | 下一首、多次跳过、仅浏览 / 喜欢歌曲、自然结束 | `fm_trash` / scrobble 写入数为 0，跳过不附带取消喜欢；用户明确喜欢操作仍只走既有喜欢意图 |
| V8-F07 | 不喜欢成功、重复点击 / 两页同目标、过期目标 / 非 FM 目标、发送前取消 | 同一已接纳目标最多一次发送；非法 / 未发送为 0；成功只在仍为当前目标时推进一次 |
| V8-F08 | 明确拒绝、发送后超时 / 取消、损坏回执、成功后 Cookie 保存失败 | 成功 / 拒绝 / 未发送 / 未知独立；无自动重发；未知不自动 Next；已获回执不因存储失败丢失或重发 |
| V8-F09 | 反馈在途期间手动 Next / 自然结束 / 暂停 / 退出 FM / 换账号；未知反馈后重新开页 | 迟到反馈不跳过新曲、不修改新会话；没有可信查询时不假回查；普通 Next 可用但不会重发反馈 |
| V8-F10 | FM 运行 / 耗尽 / 反馈未知时关闭最后页、重开、进程重启、恢复旧曲目 | 补取和反馈资格不恢复；正常队列按暂停 / 静默恢复；零自动联网、零自动出声、零写重放 |

F03 的各等待点和请求进行中取消均必须测试；不可用链必须真的跨批次执行到边界，不能只测一个上限常量。F07 / F08 的写调用日志包含目标及操作身份，避免“恰好总数为 1 但写错曲目”也通过。

## 13. 真实账号与 Host 验收（M）

完成本地自动验证后单独执行，未执行就标待验。FM“不喜欢”会改变账号推荐偏好，不是可随意回滚的测试操作；只对用户明确选定的测试歌曲执行一次，记录实际回执或未知结果，不以清理为理由再发逆向操作。普通浏览与下一首不得偷偷附带反馈。

| ID | 人工步骤 | 完成依据 |
| --- | --- | --- |
| V8-M01 | 每日推荐、个性 / 通用歌单、榜单、空或失败状态、歌单播放 / 收藏 | 真实来源、身份、字段和权限可解释；与自动夹具的差异已更新契约 |
| V8-M02 | 歌曲行和播放条进入多歌手 / 专辑、分页、返回、加入 / 播放已加载 | 跳转目标正确，顺序和范围正确，无额外自动播放 |
| V8-M03 | 显式开始 FM、连续听歌、Next、暂停 / 继续、结束；指定曲目一次不喜欢 | 下一首与反馈差异清楚；真实音频正常；反馈按实际结果记录，超时不反复重发 |
| V8-M04 | 本地最近 / 网易最近 / 网易听歌排行及实际支持范围，播放后重新查看 | 来源 / 时间 / 数量含义准确，不承诺立即计入远端；无本地记录混写 |
