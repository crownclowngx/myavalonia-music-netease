## 歌单与账号

音乐页顶部“我的歌单”读取当前已核验账号，自建/收藏以 creator ID 区分。选择歌单后点击“打开所选歌单”进入曲目页；“更多歌单”继续读取，曲目使用独立上一页/下一页，每页最多 50 首。刷新替换浏览快照，不改变正在播放的单曲。

歌单页每次最多 30 个，去重后仍按服务端原始数量推进 offset，无进展终止；最多展示 1,000 个。详情使用 `n=0` 取得 trackIds，最多保留 10,000 个有序 ID；重复 ID 保留独立位置，资料缺失显示占位。计数不一致或超限明确标为不完整，不能被后续播放全部当作完整来源。

资料按需批量读取、缓存最多 500 首；当前只维持一页 50 行，列表继续使用虚拟化。批量响应按 ID 回填，不假定服务端顺序；每个 Document 独立浏览。账号身份在登录协调器锁内随 epoch/凭据版本捕获；退出立即清空个人浏览状态，迟到结果不能覆盖新页面或新账号。

## 分工与协议

`IPlaylistCatalogApi` 是只读业务边界，`NeteasePlaylistApi` 解析歌单含义，`MusicRequestExecutor` 复用会话提交/取消/错误规则，`PlaylistBrowser` 管理页面投影，`PlaylistView` 只绑定和展示。没有通用仓储或事件总线。

`/api/user/playlist` 使用 weapi；`/api/v6/playlist/detail` 和批量 `/api/v3/song/detail` 使用 eapi。保留 15 秒/1 MiB 限制，超限拒绝，未全局扩大响应上限。限流与内容拒绝不会注销账号；只有明确会话失效撤销当前账号。

V4.3 已接入定位滑块，原生指定起点采用先暂停启动、控制门内定位、确认后输出；不在原生回调查询或控制媒体。对应离线 PCM 和真实 MP3 证据见实施记录，不代表真实声卡或 Host 验收通过。

## 共享队列与页面寿命

歌单支持播放全部、从选中位置播放、下一首播放与追加。整单播放接纳完整 ID 快照，不受当前 50 行分页限制。搜索直接播放会替换为单项队列；追加空队列只选中第一项，须点击继续才出声。播放队列提供选择播放、移除、上移/下移、清空和四种模式；当前项使用独立 EntryId，同一歌曲可在不同位置重复出现。

顺序模式末尾停止；列表循环回绕；单曲循环只在自然结束重播，手动上下首仍换曲；随机以条目无放回抽取，上一首回访实际历史。下一首播放按操作顺序优先消费。暂停/停止时手动换曲只改变待播项；播放/加载时换曲继续输出。删除当前项只在原状态为播放中时继续，停止保留队列并归零，清空移除全部。

QueueNavigator 只计算导航；PlaybackQueueCoordinator 是容器唯一队列写入者，按 AttemptId 消费一次终态；PlaybackCoordinator 负责单曲资源并在旧媒体释放后启动新曲。无地址等内容不可用最多寻找 20 个不同候选，网络/设备/协议错误立即停止自动推进。界面投影只在队列变更时重建列表，进度回报不反复复制 10,000 行。

关闭任意或最后一个 Document 后继续播放，再打开订阅同一会话。页面只释放搜索、浏览、图片及订阅；退出账号和插件 Shutdown 停止并清空个人状态。此规则替代 M1 的页面所有者停止语义。

完整 V4 开发门禁尚未接入，当前使用既有 V3 入口跑完整测试；不使用 Windows CI、发布门禁或 AIFLOW。离线原生三曲解码验证不能代替声卡听感与真实 Host 验收。

## 定位与缓冲

底部滑块仅在真实媒体可定位且时长已知时启用。鼠标拖动或键盘连按保存页面草稿，松手/松键提交一次；曲目和代次变化、视图脱离或账号撤销取消草稿。共享进度采用原生事实，失败显示实际位置及提示；负值/结尾按可播范围限制，暂停定位保持暂停。原生暂停命令也等待事件确认，避免异步 SetPause 尚未生效便执行后续 seek。

完整下载后才打开音频，加载时显示已读字节、已知总长百分比或“总大小未知”；保留 64 MiB、15 秒头部/空闲与 120 秒总预算。当前已缓冲歌曲断网仍可播放；下一首下载失败按有限规则停止。网络错误/超时最多延迟 500 ms 重试一次，410 最多重取一次地址，总媒体尝试不超过三次，取消等待立即结束；普通 403、限流、来源拒绝、解码和磁盘问题不重试。

资源保留试听起点及范围，但没有可靠的媒体时间到整曲时间映射时不猜歌词偏移。续播持久化和歌词会在后续阶段接入。
