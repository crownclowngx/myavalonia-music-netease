> 更新：2026-09-23。紧凑布局、双色资源、减少动态效果与本地自动门禁已实现。

## 页面与密度

Document 使用账号摘要、搜索/我的歌单/播放队列/歌词/最近播放五个切换入口、弹性列表和固定播放条。列表独立滚动，不把音乐区包入整页 ScrollViewer；采用虚拟化面板，不批量创建入场动画。暂停与继续共用一个位置，上下首、音量和可定位进度保持可达；四种模式在队列面板选择。

歌词支持逐行、翻译和逐字高亮，手动浏览停止跟随，可回到当前行；历史只显示本机已实际播放歌曲。账号核验后恢复队列为暂停，点击继续才出声。Document 与设置 Tool 都显示本地保存/退出清理失败及重试；完整规则见[日常播放器契约](netease-daily-player.md)。

| 获得的内容宽度 | Document 布局 |
| --- | --- |
| ≥ 900 DIP | 歌曲、歌手、专辑、时长四列；时间和音量同排 |
| 640–899 DIP | 隐藏专辑列，音量移到下一排 |
| < 640 DIP | 歌曲和歌手放入同一项的两行；保留时长；登录区上下排列 |

自动验收下限为已登录 Document 520×420；更小尺寸未作完整操作可达性保证。账号菜单放置恢复、适用时的保存重试与退出。未登录区保留微信默认扫码、App 备用扫码、取消、恢复及失败反馈；二维码区域 224 DIP，内部白底和静区不随主题反色。

Tool 按账号、播放运行库、实际状态、界面分组。宽度小于 600 DIP 时纵向排列，宽度充足时账号与运行库并排；内容超过高度时只在 Tool 内纵向滚动。已覆盖 280/320/420×900 和 640×240，低矮面板需滚动访问下方设置。

目录输入是草稿；检测、保存、已保存值、下次候选及实际加载状态继续使用原有模型。保存不等于热换运行库，内置优先规则不变。Tool 的关闭行为仍是 Hide，稳定 ID 和 Document 注册不变。

## 主题与作用域

[双色资源](../../src/MusicNetEasePlugin.Plugin/Styles/NeteaseThemeResources.axaml)只合并到三个插件 View；[紧凑样式](../../src/MusicNetEasePlugin.Plugin/Styles/NeteaseControlStyles.axaml)只作用于 `netease-*` 类。插件继承所在窗口的主题，不设置应用主题、不改 Host 资源或其他插件模板。

背景、前景、边框、选中及状态画刷采用 DynamicResource。固定白色只保留在二维码承载面；头像、二维码与封面保持原像素。标准控件、菜单和模板内部的选中反馈仍由 Fluent/Semi/Ursa 控件主题提供，因此预览与 Host 的按钮、列表细节可有差异。

音量 Slider 的 Fluent 模板默认前后各 15 DIP，加上 20 DIP 滑块需要 50 DIP。仅将外框设为 32 会裁掉滑块；当前只在该 Slider 的局部资源中把前后留白减为 6，不复制模板或覆盖全局资源。此结构依据 [Avalonia 12.1.2 Slider 源码](https://raw.githubusercontent.com/AvaloniaUI/Avalonia/12.1.2/src/Avalonia.Themes.Fluent/Controls/Slider.xaml)，并有实际 Thumb 边界断言。

## 动效与偏好

当前额外动效只有按钮背景 100 ms、结果背景 120 ms，以及登录后内容/播放状态/设置反馈 140 ms 的短淡入。没有位移、常驻频谱、旋转封面、模糊或装饰计时器。播放器进度复用既有状态节奏，StateText 实际值不变时不会重新淡入。

Tool 的“减少动态效果”立即作用于同一插件容器中的全部 View，并写入数据目录的 `ui-preferences.json`：

```json
{"schemaVersion":1,"reduceMotion":true}
```

默认允许额外动效。文件与账号、LibVLC 设置独立；读取一次，迟到读取不覆盖用户编辑；快速编辑串行合并写入，同目录临时文件完成后替换。保存失败保留当前内存选择，并显示重试按钮；损坏或未知版本给出反馈，不主动覆盖文件。

`ViewMotion` 只管理一个 View 的动效许可和最多一个淡入。它订阅当前视觉祖先的可见性、顶层最小化状态与共享偏好；隐藏、脱离、最小化、减少动态效果时撤销自有过渡并取消淡入。主题切换先取消旧色插值，再在 Dispatcher 下一周期恢复交互过渡。业务忙碌条的循环指示受同一许可控制，关闭动效后仍有状态文字。

该开关不承诺关闭第三方主题内部的全部动画。本轮没有接入未经 SDK/平台确认的系统减少动画接口；使用插件开关。恢复显示时不重放隐藏期间的状态动画。

## SOLID 与生命周期

| 对象 | 责任与依赖方向 |
| --- | --- |
| `UiPreferences` | 共享偏好与保存反馈；依赖 `IUiPreferencesStore` 和现有 UI 派发端口 |
| `UiPreferencesStore` | 单一文件格式、读取上限、原子替换；不接触账号和音频 |
| `ViewMotion` | View 可见性与有限动画；不拥有模型或播放器 |
| 三个 View | 局部资源、布局断点、订阅、图片；不执行登录或音频协议 |
| 现有页面模型 | 命令与业务状态投影，新增偏好引用和暂停显示属性；不持有控件 |
| 组合入口 | 注册每容器共享偏好并通过构造函数注入 |

使用普通 MVVM、窄存储接口、资源字典和一个生命周期辅助类，没有通用设置框架或事件总线。中文注释说明局部样式、断点、滑块模板、异步保存及订阅收口的设计原因。

主题和尺寸变化不重建模型。View 重挂释放/恢复自己的图像和订阅；目录选择器保留挂载代次、模型身份与草稿版本保护。V4 起关闭任意 Document 后继续播放，Host Shutdown/Standalone 主窗关闭才最终保存并停止；多页面共享队列，浏览仍独立，见[当前播放契约](netease-music-playback.md)。

## Standalone 预览

预览支持跟随系统/浅色/深色与并排工作区/窄 Document/窄 Tool/底部 Tool，始终复用同一套生产 View 和模型。真实 Host 的 Dock 拖拽、浮窗和回停必须另行验证。
