# V5 · Document / Tool 当前界面契约

> 更新：2026-09-23。V5 核心阶段 A–D 已接入生产代码；本地自动结果、资源测量和实际限制见 [V5 专用实施记录](../maintenance/netease-v5-ui-interaction-implementation.md)。V1–V4 的用户验收不自动覆盖 V5。

## 浏览与播放

顶部只有搜索、我的歌单、最近播放三个浏览入口。歌词与队列按需展开，固定播放栏始终提供上下首、暂停/继续、模式、音量和定位；停止在更多菜单中。每个 Document 保留关键词、页码、选择、已加载歌单和列表视图，全部 Document 共用一个播放器。

搜索、歌单和历史使用同一个 `SongRowView`。单击选择；双击、Enter 或行内播放立即播放。更多按钮、右键和 Shift+F10 打开同一组命令。选中背景与当前歌曲的静态播放标记独立。三个来源的立即播放均在当前项后插入并播放，保留原队列；当前同曲继续播放，不重复插入。只有明确的“播放全部 / 从这里播放整份歌单”替换队列。

歌单名称可以直接打开；“全部已加载 / 自建 / 收藏”仅筛选已加载数据，继续加载不被误称为全量。返回保留筛选和列表位置。详情只补当前 50 首资料，完整 ID 快照仍用于整单播放。

| 实际可用空间 | 布局 |
| --- | --- |
| 音乐区宽 ≥1120、高 ≥550 DIP | 队列作为 304 DIP 侧栏，通常对应含账号栏的 Document 高约 600 DIP |
| 不满足侧栏条件 | 同一份队列视图占主内容区，关闭返回原浏览/歌词状态 |
| 歌曲行自身宽 ≥760 DIP | 歌名、歌手、专辑分列；否则使用两行文字 |
| 播放条宽 <850 DIP | 辅助控件移到第二行；常用播放键和进度保持可见 |
| 播放条宽 ≥1120 DIP | 增加直接音量 Slider；所有尺寸都有音量弹层和静音恢复 |
| 歌词区外壳宽 ≥1000、高 ≥550 DIP | 显示 200 DIP 静态封面；关闭封面偏好时收回空间 |

自动布局覆盖 Document 1200×720、800×600、520×420，设置 Tool 280/320/420×900 与 640×240。更小窗口没有完整可达性保证。歌词为 24 DIP、窄列 20 DIP，翻译 13 DIP；行宽最多 720 DIP。仅手动浏览后出现“回到当前歌词”，仅失败后出现重试。翻译开关对有翻译的歌曲显示。

队列操作按 EntryId 增量复用行；进度不触发全量清空/重建。随机模式明确提示列表顺序不代表实际随机下一首。打开队列首次定位当前项，手动滚动后不被播放进度抢回。清空需要面板内确认，并在唯一队列写入者内原子校验版本。

本机历史按当前本地时区显示今天、昨天、更早；重新显示时检查跨日，不建立午夜循环定时器。恢复仍默认暂停；继续才取音频。完整播放和持久化边界见 [日常播放器契约](netease-daily-player.md)。

## 登录、设置与输入

登录区采用方式选择加一个生成/刷新按钮，二维码失效和待确认沿用真实登录状态。切换方式取消旧二维码，二维码始终保持白底及静区。账号菜单提供“账号与播放设置”、恢复、保存重试及退出。

SDK 3.4.1 没有公开的 Tool 激活端口，因此账号菜单在当前 Document 打开设置内容，复用容器中的 `MusicSettingsTool`；Host 注册的独立 Tool 同时保留。关闭设置返回账号按钮焦点，Esc 可以返回音乐。没有调用 Host 内部类型，也没有建立第二套账号或配置服务。

运行库正常时只显示摘要和折叠诊断，检测或加载故障展开详情。输入草稿、已保存目录、下次候选、当前实际目录始终区分；保存不意味着热换已加载库。

Enter 处理发生在曲目列表的隧道路由，避免被 ListBox 默认行为吞掉；行内按钮先选中再执行页面命令。搜索检查 TextPresenter 的公开预编辑状态，IME 候选组合期间不提交搜索。Space 不覆盖文本框、按钮、Slider、ComboBox 与列表的输入语义。Esc 优先由弹层处理，再返回队列或歌词；没有注册全局快捷键。

## 主题、反馈和偏好

界面使用中性页面/内容面与小面积红色强调，所有色值集中在 [双色资源](../../src/MusicNetEasePlugin.Plugin/Styles/NeteaseThemeResources.axaml)。几何图标只包含必要音乐操作。样式仅影响插件内显式类，继承所在窗口深浅主题；部分标准控件内部细节继续由 Host 的 Fluent/Semi/Ursa 主题提供。

按钮有悬停、按下、焦点和禁用反馈；主要播放键 40×40 DIP，行内操作 32×32 DIP。长文字截断后提供完整信息提示。加入队列使用播放栏附近 2.5 秒反馈，最多一个可取消延迟；重要失败持续保留在对应状态及详情中。

额外动效只有短背景过渡与一次性淡入，没有新增装饰循环时钟、旋转封面、模糊或频谱。隐藏、最小化、脱离视觉树及减少动态效果关闭新增动效；隐藏歌词和播放条不投递进度 UI 刷新，重新出现一次同步最新快照。

```json
{"schemaVersion":2,"reduceMotion":false,"showArtwork":true,"showTranslation":true}
```

三个偏好独立、即时生效，容器共享；旧 schema 1 保留减少动效值，并将新增两个开关默认为 true。原子写入、迟到读取不覆盖编辑、保存失败可重试。封面关闭不影响二维码。该开关不承诺改变第三方控件主题内部全部动画。

## 图片预算与所有权

网络图片只允许既有网易图片域，升级 HTTPS，不携带 Cookie，统一请求 160 档，单响应 ≤2 MiB，超时 10 秒。容器级 `AccountImageCache` 最多两个在途下载、64 个等待/在途键，当前曲目优先于等待中的缩略图；同键合并，各消费者取消互不干扰，最后消费者取消下载。压缩缓存按 LRU 控制在 8 MiB / 128 条内。

`ArtworkCache` 由同容器 `ArtworkContext` 持有；View 只拿租约，不共享 Image 控件。位图预算 16 MiB / 24 项，当前引用计入限制；空间不足且全部在用时显示占位。解码前读取 PNG/JPEG 尺寸，拒绝异常或源像素超过 4,194,304 的图，按最长边最多 256 物理像素缩略解码，比方案的 512 上限更保守。未知/动画格式使用几何占位，不新增解码运行时依赖。最后引用归还后才允许释放；账户切换清缓存并撤销旧代次，迟到结果不能复活旧图片。

头像、当前封面、可见歌单缩略图共享预算。歌词展开大封面复用已取得字节和位图；搜索/队列/历史行不加载封面。隐藏、虚拟化回收、关闭偏好或重挂释放 View 引用；缓存可保留有界的零引用热数据。二维码独立遵循登录流程寿命。

## SOLID 分工

| 对象 | 单一责任 |
| --- | --- |
| `MusicWorkspace` / `MusicNavigation` | 搜索意图与组合 / Document 导航记忆 |
| `PlayerBarWorkspace` / `TimelineWorkspace` | 共享播放事实投影 / 定位草稿与提交 |
| `SongRowView` / `SongListBox` | 复用展示、选择和输入路由；不接触网络或音频 |
| `QueueWorkspace` / `PlaybackQueueCoordinator` | 增量页面投影 / 唯一队列写入者与原子播放意图 |
| `IAccountImageSource` / `AccountImageCache` | 无凭据图片端口 / 压缩缓存、优先调度和取消 |
| `ArtworkContext` / `ArtworkCache` / `ArtworkImage` | 容器组合 / 位图租约与解码预算 / View 可见性与请求寿命 |
| `UiPreferences` / `UiPreferencesStore` | 偏好与反馈 / 版本迁移和原子文件 |

采用构造注入、普通 MVVM、资源字典、缓存装饰器和引用租约，没有引入通用事件总线、插件内服务定位器或新 UI 框架。生命周期与竞态原因使用中文注释。Standalone 和真实 Host 复用生产实现，但 Headless/Standalone 截图不代表真实 Dock、DPI 或声卡验收。
